# Módulo de Jonathan

- **Proyecto:** AvisIA
- **Para quién es:** estudiantes del IAE que van a faltar a clases (por una competencia, una cita médica, un viaje, etc.).
- **Funcionalidad central:** el estudiante elige la fecha, las horas y el motivo de su ausencia; AvisIA cruza esos datos con su horario semanal y genera un correo listo para enviar a cada profesor afectado (uno por profesor).
