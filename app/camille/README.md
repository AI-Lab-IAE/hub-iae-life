# Módulo de Camille

- **Proyecto:** IAE School Guide
- **Para quién es:** estudiantes del Instituto Alberto Einstein que necesitan encontrar información del colegio durante el año escolar.
- **Problema que resuelve:** la información escolar está repartida en muchos lugares; esta guía la reúne en uno solo.
- **Funcionalidad central:** una página principal clara con navegación a seis secciones (mapa, contactos, documentos, calendario, anuncios e información general), cada una con datos de ejemplo marcados como ficticios.
